# Python - More Classes and Objects

This project is part of the FIT Higher Level Programming curriculum.

## Description

The project introduces more concepts of Python classes and objects, including:

- Creating classes
- Defining attributes
- Using instance and class attributes
- Property getters and setters
- Special methods (`__init__`, `__str__`, `__repr__`, `__del__`)
- Object representation
- Static methods and class methods

## Requirements

- Ubuntu 20.04 LTS
- Python 3.8.5
- All files must start with `#!/usr/bin/python3`
- Code must follow `pycodestyle` (version 2.8.0)
- No external modules unless specified
- All files must be executable
