i# Python - Everything is Object

## Description

This project is part of the FIT Software Engineering curriculum. It introduces the concept that **everything in Python is an object**. Through a series of exercises, the project explores object identity, mutability, references, assignments, and how Python manages objects in memory.

The goal is to develop a deeper understanding of Python's object model rather than simply learning syntax.

## Learning Objectives

By completing this project, I learned to:

* Understand that everything in Python is an object.
* Differentiate between mutable and immutable objects.
* Understand object identity and object type.
* Use the `id()` and `type()` functions.
* Explain the difference between equality (`==`) and identity (`is`).
* Understand variable assignment and object references.
* Recognize how lists, tuples, strings, and dictionaries behave in memory.
