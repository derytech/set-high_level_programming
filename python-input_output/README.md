# Python - Input/Output

## Description
This directory contains projects and tasks focusing on Python file handling, input/output operations, reading and writing files using UTF-8 encoding, using the `with` statement, working with JSON serialization and deserialization, and handling command-line arguments.

## Tasks

| File | Description |
| --- | --- |
| `0-read_file.py` | Python function that reads a UTF-8 text file and prints its content to stdout. |

## Requirements
* All files interpreted/compiled on Ubuntu 20.04 LTS using `python3` (version 3.8.5)
* All Python files strictly follow `pycodestyle` (version 2.8.*)
* All files are executable (`chmod +x`)
* All modules and functions have meaningful docstrings explaining their purpose
