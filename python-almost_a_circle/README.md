# Python - Almost a Circle

## Description
This project is a comprehensive review of Object-Oriented Programming (OOP) in Python. It covers class design, inheritance, method overriding, unit testing with `unittest`, static/class methods, and object serialization/deserialization using JSON and CSV formats.

---

## Learning Objectives
* How to unit test a complete project using the `unittest` module.
* How to serialize and deserialize classes using JSON (`json.dumps` and `json.loads`).
* How to implement inheritance, arguments handling (`*args` and `**kwargs`), and custom object representation (`__str__`).
* How to enforce PEP 8 style guide requirements using `pycodestyle`.

---

## Environment & Requirements
* **OS:** Ubuntu 20.04 LTS
* **Language:** Python 3.8.5
* **Style Guide:** `pycodestyle` (version 2.8.*)
* **Testing Framework:** Python `unittest` module
