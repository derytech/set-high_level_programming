=============================
How to Use 0-add_integer.py
=============================

This module defines the ``add_integer`` function.

Usage
=====

Loading the function:
    >>> add_integer = __import__('0-add_integer').add_integer

Passing two positive integers:
    >>> add_integer(1, 2)
    3

Passing a positive and a negative integer:
    >>> add_integer(100, -2)
    98

Passing a single integer (uses default b = 98):
    >>> add_integer(2)
    100

Passing floating-point numbers (cast to integers):
    >>> add_integer(100.3, -2)
    98

    >>> add_integer(2.6, 3.4)
    5

    >>> add_integer(-2.5, -3.5)
    -5
