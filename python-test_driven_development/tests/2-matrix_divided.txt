==============================
How to Use 2-matrix_divided.py
==============================

This module defines the ``matrix_divided`` function.

Usage
=====

Loading the function:
    >>> matrix_divided = __import__('2-matrix_divided').matrix_divided

Dividing a 2x3 matrix of integers:
    >>> matrix = [[1, 2, 3], [4, 5, 6]]
    >>> matrix_divided(matrix, 3)
    [[0.33, 0.67, 1.0], [1.33, 1.67, 2.0]]

Verifying original matrix is unmutated:
    >>> matrix
    [[1, 2, 3], [4, 5, 6]]

Dividing matrix containing floats:
    >>> matrix_divided([[1.5, 2.5], [3.5, 4.5]], 2)
    [[0.75, 1.25], [1.75, 2.25]]

Dividing by float divisor:
    >>> matrix_divided([[1, 2], [3, 4]], 0.5)
    [[2.0, 4.0], [6.0, 8.0]]

Dividing matrix with negative numbers:
    >>> matrix_divided([[-1, -2], [-3, -4]], 2)
    [[-0.5, -1.0], [-1.5, -2.0]]

Infinity and NaN Edge Cases
==========================

Divisor is float('inf'):
    >>> matrix_divided([[1, 2], [3, 4]], float('inf'))
    [[0.0, 0.0], [0.0, 0.0]]

Matrix contains float('inf') or float('nan') with integer divisor:
    >>> matrix_divided([[1, float('inf')], [2, 3]], 2)
    [[0.5, inf], [1.0, 1.5]]

    >>> matrix_divided([[1, float('nan')], [2, 3]], 2)
    [[0.5, nan], [1.0, 1.5]]

Matrix contains float('inf') or float('nan') with float('inf') or float('nan') divisor:
    >>> matrix_divided([[1, float('inf')], [2, 3]], float('inf'))
    [[0.0, nan], [0.0, 0.0]]

    >>> matrix_divided([[1, float('nan')], [2, 3]], float('nan'))
    [[nan, nan], [nan, nan]]
