=================================
How to Use 5-text_indentation.py
=================================

This module defines the ``text_indentation`` function.

Usage
=====

Loading the function:
    >>> text_indentation = __import__('5-text_indentation').text_indentation

Printing text with punctuation (., ?, :):
    >>> text_indentation("Hello. World? How are you: fine.")
    Hello.
    <BLANKLINE>
    World?
    <BLANKLINE>
    How are you:
    <BLANKLINE>
    fine.
    <BLANKLINE>

Text without matching punctuation:
    >>> text_indentation("Hello World")
    Hello World

Text with leading and trailing spaces:
    >>> text_indentation("   Hello.   World?   ")
    Hello.
    <BLANKLINE>
    World?
    <BLANKLINE>

Text with newlines and leading spaces:
    >>> text_indentation("Line 1\n  Line 2.")
    Line 1
    Line 2.
    <BLANKLINE>

Empty string:
    >>> text_indentation("")
